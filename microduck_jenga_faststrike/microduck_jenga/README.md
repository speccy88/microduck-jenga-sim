# Microduck Jenga simulation and training

This project contains experimental, placement-controlled Jenga simulation and training code. A successful three-block PPO policy has not been established. See the repository root README and `docs/local_rtx_training.md` for validation, installation requirements and current limitations.

The project is simulation-only. No physical robot execution or safety validation is claimed. Code derives from Pollen Robotics' Microduck RL project and is Apache-2.0; robot meshes have separate CC-BY-NC-SA-4.0 terms. Model weights are not included.
